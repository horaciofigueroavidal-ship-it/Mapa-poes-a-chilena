# Mapa de la poesía chilena

Bóveda de Obsidian construida a partir del índice de Naín Nómez, *Antología crítica de la poesía chilena*.

- `Poesía chilena.md`: nota central → movimientos → poetas → obras.
- `Mapa de la poesía chilena.canvas`: el mismo mapa con posiciones fijas.
- `Autores/`: descripción de cada poeta tomada de [Memoria Chilena](https://www.memoriachilena.gob.cl) (Biblioteca Nacional de Chile), con los poemas antologados.
- `Obras/`: ficha de cada libro digitalizado, con enlace a su página y a su PDF en Memoria Chilena.

Los PDFs no se incluyen en el repositorio; cada nota de obra enlaza al PDF en línea.
Para abrir: Obsidian → «Open folder as vault» → esta carpeta.
